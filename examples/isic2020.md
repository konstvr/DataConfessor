# Worked example: ISIC-2020 (dermoscopy, 33,126 images, 2,056 patients)

The dataset the tool was calibrated on, and the one place you can compare its output with a
published number. Everything below runs from the public archive, with no code written.

## 1. Get the data

The SIIM-ISIC 2020 training archive: the 256-pixel thumbnails and
`ISIC_2020_Training_GroundTruth_v2.csv`, which carries `image_name`, `patient_id` and
`target`. Any local copy of those two things works.

## 2. Build the manifest

```bash
dataconfessor init /data/isic2020/thumbnails_256 \
    --labels-csv /data/isic2020/ISIC_2020_Training_GroundTruth_v2.csv \
    --out isic_manifest.csv
```

The columns are guessed (`image_name`, `target`, `patient_id`) and all 33,126 files match.

## 3. Check

```bash
dataconfessor check isic_manifest.csv
```

Expect 33,126 records, 2,056 patients, a median of 12 records per patient (mean 16.1) and
584 malignant records against 32,542 benign. If your numbers differ, you have a different
subset.

## 4. Screen

```bash
dataconfessor screen isic_manifest.csv --device cuda \
    --patients isic_flagged.csv --out isic_summary.json --report isic_report.html
```

The first run decodes every image into a cache (about 5 GB; put it on a fast disk with
`--cache-dir`). The screen itself takes a few minutes on one GPU.

## What to expect

In the source study, this screen on this dataset:

| | |
|---|---|
| self-consistency | 0.82 |
| flagged | 411 of 2,056 patients (20%) |
| recall of the top-5% tail of the audited model | 70.9% (3.5x random flagging) |
| cost | 7.4 GPU-minutes, 0.0074 kWh, against 1.55 kWh for the full audit |

The flagged cohort is almost exactly the melanoma cohort: 407 of the 411 flagged patients
hold 561 of the 579 melanoma images. That is the clearest illustration of why the flags are
not a deletion list — removing them would remove the disease.
